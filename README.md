# UK Local Authority Traffic Analysis

## Power BI Dashboard

An interactive Power BI dashboard analysing UK local authority traffic and vehicle trends.

### Key Insights
- Motor vehicle trends from 1993–2025
- Car and taxi trends over time
- Vehicle volumes by local authority
- Traffic per kilometre by local authority
- Interactive filtering by year and local authority

### Tools Used
- Power BI
- Data visualisation
- Data analysis
